# BiSFit

WoW 포에버에서 **직업 방어구를 우선하면 혼합 BiS와 성능이 얼마나 달라질까요?** BiSFit은 같은 전문화의 프리레이드 장비 세트를 좌우로 비교합니다. 현재 주술사와 드루이드를 지원하며 필요에 따라 지원 직업을 늘릴 예정입니다. 추천 범위는 현재 데이터에 수록된 후보 세트입니다.

## 설치하고 첫 비교

GitHub Actions에서 성공한 **Test and package the addon** 실행을 열고 **Artifacts → BiSFit-install**을 다운로드합니다. 내려받은 압축 안의 `BiSFit-<버전>.zip`을 풀어 `World of Warcraft/_forever_/Interface/AddOns/BiSFit/BiSFit.toc`가 되게 합니다. 게임을 다시 실행한 뒤 채팅에 `/bis`를 입력합니다.

1. 직업과 전문화를 선택합니다. 처음 여는 전문화는 왼쪽에 **사슬 우선** 또는 **가죽 우선**, 오른쪽에 **혼합 허용** 세트를 표시합니다. 왼쪽 재질 버튼을 누르면 사슬만 또는 가죽만으로 제한할 수 있습니다.
2. 두 열에는 같은 적중 목표와 고정 조건이 적용됩니다. 예를 들어 고술이 사슬만으로 적중을 채울 수 없다면, 왼쪽은 목표를 채우면서 가죽·천을 가장 적게 섞은 세트, 오른쪽은 목표를 채운 후보 중 평균 DPS가 가장 높은 세트입니다. 같은 세트가 양쪽에서 1위일 수도 있습니다.
3. 아이템을 좌클릭하면 해당 부위 후보가 열립니다. 후보를 선택하면 해당 열에서 그 아이템을 포함한 세트를 보여줍니다. 해당 열의 **미리보기 · 추천으로 복귀**를 누르면 저장한 조건으로 돌아갑니다. 한 부위를 계속 쓰려면 우클릭하세요. 같은 아이템을 다시 우클릭하거나 **고정 해제**를 누르면 풀립니다.

**다시 열 때는 바로 비교하세요.** 고정한 부위·아이템, 재질 모드, 직접 설정한 적중 목표는 캐릭터의 전문화별로 저장됩니다. 해당 전문화로 돌아오면 자동 적용됩니다. 목표를 바꿀 때만 값을 입력하고 **조회**를 누르면 됩니다.

## 적중과 재질

재질 제한은 머리·어깨·가슴·손목·손·허리·다리·발에 적용합니다. **사슬만·가죽만**은 이 여덟 부위의 재질을 제한합니다. **우선** 모드는 목표 미달분이 가장 작은 후보 중 다른 재질 부위가 가장 적은 세트를 고른 뒤 역할별 성능을 비교합니다. **혼합 허용**은 같은 적중 조건에서 착용 가능한 모든 재질을 허용합니다.

왼쪽 열의 달성 여부는 표시된 세트 기준입니다. 한 부위만 섞으면 **목표 달성 · 천 어깨 1부위**처럼 표시합니다. 현재 고정·제외 조건에서 순수 재질의 등록 장비 최대 적중이 목표보다 낮으면 **사슬만으론 2.2%p 부족 · 안돼 돌아가~**처럼 별도로 안내합니다. 고정·제외 조건을 만족하는 후보 자체가 없으면 **조건에 맞는 후보 없음**을 표시합니다.

| 역할 | 레이드 목표 | 적중 특성 |
| --- | --- | --- |
| 고양 / 정기 | 근접 8% / 주문 17% | 해일의 집중 1점당 1%p, 최대 5점 |
| 표범·곰 / 조화 | 근접 8% / 주문 17% (곰은 생존 평가를 위해 장비 목표 기본값 0%) | Nature’s Reach 1점당 2%p, 최대 2점 |
| 복원 주술사 / 회복 드루이드 | 치유 기준 | 장비 적중 조건 생략 |

장비의 기본 적중 평점 10을 1%로 환산합니다. 종족·공대 보정이나 세트 보너스로 확보하는 적중은 직접 입력에서 조정하세요. 특성 API를 사용할 수 없는 클라이언트에서는 포인트를 직접 입력하세요. 주술사 시뮬레이션은 수록된 참조 빌드를 사용하며, 입력한 특성 포인트는 장비 적중 목표에 반영합니다. [공격대 적중과 직업별 보정](https://www.method.gg/wow-forever/how-does-hit-chance-work-in-wow-forever) · [WoWF 고양](https://wowf.io/ko/bis/shaman/enhancement) · [WoWF 정기](https://wowf.io/ko/bis/shaman/elemental)

**내 특성**으로 현재 포인트를 읽거나, 다른 빌드의 포인트를 입력해 **레이드 목표 적용**을 누르세요. 직접 입력한 장비 적중 목표는 그대로 사용합니다.

## 수치 읽기

아이템 툴팁의 **EP**는 측정할 후보를 추리는 능력치 점수입니다. 양쪽 열의 **DPS·TMI·지속 HPS**는 세트 전체의 평가값입니다. 데이터 갱신 때 계산하고 게임에서는 저장된 결과를 조회합니다.

| 역할 | 지원 전문화 | 장비 평가 기준 |
| --- | --- | --- |
| 탱 | 야성 드루이드(곰) | 세트당 180초 전투를 256회 측정합니다. 6초 동안 받은 피해가 얼마나 집중되는지 나타내는 TMI가 낮은 순입니다. 동점이면 초당 받은 피해가 적은 세트를 선택합니다. |
| 딜 | 고양·정기 주술사, 조화·야성(표범) 드루이드 | 평균 5분(4~6분) 단일 대상 전투에서 평균 DPS가 높은 순입니다. 네 딜 전문화 모두 장비 세트당 1,600회 측정합니다. |
| 힐 | 복원 주술사, 회복 드루이드 | 180초간 마나로 감당할 수 있는 지속 HPS가 높은 순입니다. 5초당 고정 마나 회복량(MP5)과 전투 종료 시 남는 마나도 표시합니다. |

하단의 **혼합 대비**는 왼쪽 세트 값에서 오른쪽 값을 뺀 차이입니다. 예를 들어 고술의 −3 DPS는 사슬 쪽의 기대 DPS가 3 낮다는 뜻입니다. 능력치 차이는 아이템 기본 수치의 합으로, 적중은 평점으로 표시합니다. **계산 기준 ⓘ**에서 측정 조건과 딜 세트의 표준오차를 확인할 수 있습니다.

**파밍 비교** · 서로 다른 장비 줄은 ↔로 표시합니다. 양쪽이 적중 목표를 충족하면 오른쪽 비교 패널에 전체 세트의 DPS 차이·백분율·교체 부위 수를 표시합니다. 왼쪽이 순수 직업 방어구 세트이면 계산 기준에서 나머지 장비를 그대로 두고 한 부위만 교체했을 때 적중을 유지하며 얻을 수 있는 최대 측정 DPS 이득도 볼 수 있습니다. 계산 기준에서 바뀐 부위와 각 열의 획득 가능 목록 기준 최대 장비 적중을 확인할 수 있습니다. 고정 장비와 제외 조건도 최대치 계산에 반영합니다. 임시 미리보기는 최대치 계산에서 제외합니다.

일반 조회의 근접한 딜 후보는 데이터 갱신 때 서로 다른 난수로 세트당 6,400회 추가 측정합니다. 계산 기준의 약 95% 오차 범위는 추가 측정에서 얻은 두 평균의 차이에 대한 값입니다. 슬롯을 고정하거나 미리보기로 선택한 조합에는 추가 측정값이 없을 수 있습니다.

## 데이터 출처

두 직업 모두 WoWSims Forever의 아이템 DB를 사용합니다. 등록한 프리레이드 획득처와 확인된 제작품에서 후보를 추리며, 아이템별 획득처는 게임 툴팁에서 확인할 수 있습니다. [획득처·직업별 대조 목록·계산 근거](SOURCES.md)

## 업데이트와 배포

- **코드 변경 검증** · PR과 `main` 푸시에서 Lua 테스트를 실행하고 커밋에 포함된 데이터로 설치 ZIP을 만듭니다.
- **데이터 갱신** · Actions가 활성화된 저장소의 기본 브랜치에서 매주 월요일 06:17(한국 시간)에 WoWSims 데이터를 다시 받아 계산합니다. 수동 실행 시 커밋을 지정할 수 있습니다. 새 던전이나 페이즈는 획득처와 제작 재료를 확인한 뒤 `dev/catalog.ts`에 추가합니다.
- **갱신 결과 보관** · 주간 실행 기록의 `BiSFit-tested-build` 아티팩트에서 `BiSFit-<버전>.zip`을 꺼냅니다. 그 안의 `Data.lua`, `PlannerData.lua`, `HitCaps.lua`, `ConfirmedDPS.lua` 네 파일을 함께 저장소 루트에 반영하고 PR로 커밋하면 다음 설치 ZIP에도 같은 데이터가 포함됩니다.
- **공개 배포** · 게임에서 쓸 때와 CurseForge에서 배포할 때 모두 설치 ZIP을 씁니다. 개발 중에는 ZIP을 직접 풀어 포에버 클라이언트에서 확인할 수 있습니다. 현재 워크플로는 설치 ZIP을 생성하며 CurseForge 게시는 별도로 진행합니다.

node dev/refresh.ts ../wowsims-forever ./measure
