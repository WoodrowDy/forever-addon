# BiSFit

BiSFit은 WoW 포에버의 프리레이드 장비를 역할별로 비교하는 애드온입니다. 현재 주술사와 드루이드를 지원하며, 지원 직업은 앞으로 늘릴 예정입니다. 게임에서 `/bis`를 입력해 직업과 전문화를 선택하세요.

## 설치

GitHub Actions에서 성공한 **Test and package the addon** 실행을 열고 **Artifacts → BiSFit-install**을 다운로드합니다. 내려받은 압축 안의 `BiSFit-<버전>.zip`을 풀어 `World of Warcraft/_forever_/Interface/AddOns/BiSFit/BiSFit.toc`가 되게 합니다. 게임을 다시 실행한 뒤 채팅에 `/bis`를 입력합니다. 별칭은 `/bisfit`, `/sfit`입니다.

## 조회하기

1. 직업과 전문화를 선택합니다. 딜·탱 역할은 **장비 근접/주문 적중 (%)**에 장비로 확보할 최소값을 입력하고 **조회**를 누릅니다. 회복 역할은 적중 조건을 쓰지 않습니다.
2. **내 특성**은 현재 캐릭터의 해당 특성 포인트를 읽어 레이드 목표에서 차감합니다. 다른 빌드는 포인트를 입력하고 **레이드 목표 적용**을 누릅니다. 직접 입력한 장비 목표에는 특성 보정을 다시 차감하지 않습니다.
3. **사슬만 / 가죽만**을 누르면 **사슬 우선 / 가죽 우선**으로 전환됩니다. 우선 모드는 목표를 달성하는 후보 중 다른 재질을 가장 적게 사용한 세트를 고릅니다. 같은 부위 수에서는 아래 역할별 평가 기준으로 순위를 정합니다. 혼합 열은 재질 수 제한 없이 조회합니다.
4. 목표를 채울 수 없으면 후보 중 가장 높은 적중을 확보한 세트와 부족분을 보여줍니다. 엄격한 재질 조회에서 실제 미달일 때만 **목표 미달 (없어 돌아가)**를 표시합니다. 고정이나 제외 조건으로 후보 자체가 없으면 **조건에 맞는 후보 없음**을 표시합니다.
5. 결과 장비를 좌클릭해 해당 부위의 후보 목록을 열고, 후보를 클릭하면 선택한 열에서 그 아이템을 포함한 세트로 교체됩니다. 우클릭은 한 부위 고정/해제이며 조회 조건을 바꿔도 고정은 유지됩니다. 직업·전문화별 목표, 고정, 재질 모드는 캐릭터별로 저장됩니다. 툴팁에서 기본 EP와 수록된 획득처를 확인합니다. 단일 부위 교체 결과가 측정되어 있으면 같은 툴팁에 역할별 지표 차이가 표시됩니다.

재질 제한은 머리·어깨·가슴·손목·손·허리·다리·발에 적용합니다. 혼합 조회는 주술사의 사슬·가죽·천, 드루이드의 가죽·천을 허용합니다. 평판 보상과 T0.5 연퀘 장비는 각각 제외할 수 있습니다.

## 레이드 적중과 BiS 기준

| 역할 | 레이드 목표 | 적중 특성 |
| --- | --- | --- |
| 고양 / 정기 | 근접 8% / 주문 17% | 해일의 집중 1점당 1%p, 최대 5점 |
| 표범·곰 / 조화 | 근접 8% / 주문 17% (곰은 생존 평가를 위해 장비 목표 기본값 0%) | Nature’s Reach 1점당 2%p, 최대 2점 |
| 복원 주술사 / 회복 드루이드 | 치유 기준 | 장비 적중 조건 생략 |

장비의 기본 적중 평점 10을 1%로 환산합니다. 종족·공대 보정이나 세트 보너스로 확보하는 적중은 직접 입력에서 조정하세요. 특성 API를 사용할 수 없는 클라이언트에서는 포인트를 직접 입력하세요. 주술사 시뮬레이션은 수록된 참조 빌드를 사용하며, 입력한 특성 포인트는 장비 적중 목표에 반영합니다. [공격대 적중과 직업별 보정](https://www.method.gg/wow-forever/how-does-hit-chance-work-in-wow-forever) · [WoWF 고양](https://wowf.io/ko/bis/shaman/enhancement) · [WoWF 정기](https://wowf.io/ko/bis/shaman/elemental)

**추천 순서**

1. 획득처와 착용 조건을 확인하고, 전문화별 EP로 측정할 장비 조합을 추립니다.
2. 아래 조건으로 후보 세트의 성능을 미리 계산해 저장합니다.
3. 게임에서 조회하면 고정·제외·재질 조건을 적용하고, 장비 적중 목표를 우선합니다. 재질 우선 모드에서는 다른 재질을 쓴 부위가 적은 순으로, 그다음은 역할별 성능순으로 고릅니다.

| 역할 | 지원 전문화 | 장비 평가 기준 |
| --- | --- | --- |
| 탱 | 야성 드루이드(곰) | 세트당 180초 전투를 256회 측정합니다. 6초 동안 받은 피해가 얼마나 집중되는지 나타내는 TMI가 낮은 순입니다. 동점이면 초당 받은 피해가 적은 세트를 선택합니다. |
| 딜 | 고양·정기 주술사, 조화·야성(표범) 드루이드 | 180초 단일 대상 전투에서 평균 DPS가 높은 순입니다. 네 딜 전문화 모두 장비 세트당 1,600회 측정합니다. |
| 힐 | 복원 주술사, 회복 드루이드 | 180초간 마나로 감당할 수 있는 지속 HPS가 높은 순입니다. 5초당 고정 마나 회복량(MP5)과 전투 종료 시 남는 마나도 표시합니다. |

두 직업은 같은 WoWSims DB와 페이즈·레벨·품질·획득처 기준을 사용합니다. 드루이드의 가죽·천, 반지·장신구 쌍, 무기와 우상은 독립적으로 수집합니다. WOWF 비교 목록에서 누락된 아이템은 갱신 로그에 역할·부위·ID·첫 제외 사유를 남깁니다. 자동 수집 범위는 등록한 획득처에 한정되며 제작품은 확인한 목록을 사용합니다. 드루이드는 적중 평점과 다른 재질 수별로 EP 상위 조합을 생성하고, 재질 수와 1% 간격의 적중 목표별 상위 2개를 모아 실제 평가합니다. 순위·고정·교체는 수록된 최종 후보 내에서 지원합니다. 표본 수에 따른 측정 오차가 있습니다.

아이템 툴팁 EP는 후보 선별용 점수입니다. 곰은 기존 가중치에서 방어 능력치만 사용합니다. 회드는 치유력·고정 MP5·지능에 각각 1·1.86·0.77의 선별 가중치를 둡니다. 이 가중치는 제작자가 설정한 근삿값입니다.

복술은 기존 참조 빌드의 하급 치유의 물결 6단계, 회드는 무특성 치유의 손길 10단계(기본 평균 1946.4, 치유력 계수 1, 기본 3.5초, 마나 755)로 비교합니다. 회드 엔진은 장비 능력치만 제공하므로 두 힐러의 지속 HPS는 애드온의 단일 주문 계산값입니다. 고정 MP5를 초당 균등 회복으로 처리하고 초과 치유, 정신력 회복, 소모품, HoT 중첩, 발동에 의한 마나 수급은 제외합니다. 종료 마나는 해당 조건의 추정치입니다.

## 수치 읽기

| 항목 | 계산 방법 |
| --- | --- |
| 고양·정기 | WoWSims Forever의 해당 특성 기본 특성·버프·소모품·딜 사이클을 사용합니다. 타우렌 60레벨, 우두머리 63레벨 하나, 고정 180초, 무마부, 무기 스왑 해제, 세트당 1,600회로 통일했습니다. 수치 옆 계산 조건에 표준오차도 표시합니다. |
| 복원 | 하급 치유의 물결 6단계를 단일 대상에게 연속 시전한다고 가정합니다. 평균 기본 치유 820, 치유력 계수 0.429, 기본 시전 1.5초, 마나 380을 사용합니다. 정화 5점과 해일의 집중 5점을 적용하며 평균 1회 치유량에 주문 극대화, 시전 HPS에 주문 가속이 반영됩니다. 1회 마나는 361입니다. 초과 치유, 물의 보호막, 일시 발동, 연쇄 치유는 이 수치에서 제외됩니다. |
| 능력치 차이 | 왼쪽 세트의 아이템 기본 능력치 합에서 혼합 세트의 합을 뺍니다. 힘·민첩·체력·지능·치유력·주문 피해·적중 평점 중 값이 달라지는 항목을 표시합니다. |
| 역할 지표 차이 | 왼쪽 세트와 혼합 세트의 역할 지표 차이입니다. 곰은 TMI가 낮을수록 유리합니다. |

**계산 기준 ⓘ**에서 전투 조건과 데이터 날짜를 확인할 수 있습니다. 딜 세트에는 평균 DPS의 표준오차도 표시합니다. 조드와 표범은 무버프 타우렌의 역할별 전투 행동 목록을 사용합니다. 장비 순위는 같은 전문화와 참조 빌드 안에서 비교하세요. 근소한 DPS 차이는 반복 측정에서 순서가 바뀔 수 있습니다.

## 아이템과 파밍 범위

두 직업의 장비 ID와 기본 획득처는 고정 버전의 WoWSims 아이템 DB에서 가져옵니다. 던전·보스, 퀘스트, 제작, 상인·평판 후보의 포함 조건과 개별 보완 출처는 저장소에서 확인할 수 있습니다. [획득처별 근거 자료](SOURCES.md) · [공통 선별 기준](dev/catalog.ts) · [드루이드 수집기](dev/druid_catalog.ts)

드루이드 장비의 독립 대조 목록은 역할별 WOWF.IO 페이지입니다. [조화](https://wowf.io/ko/bis/druid/balance) · [표범](https://wowf.io/ko/bis/druid/feral-dps) · [곰](https://wowf.io/ko/bis/druid/feral-tank) · [회복](https://wowf.io/ko/bis/druid/restoration)

주술사 초기 목록은 WoWSims Forever의 페이즈 1 아이템과 획득 경로에서 선별한, 아이템 레벨 48 이상의 고정 능력치 희귀·영웅 장비입니다. 검은바위 나락·첨탑, 스칼로맨스, 스트라솔름, 혈투의 전장, 마라우돈의 지정 보스와 검은아귀 요새 등 확인한 개별 경로를 담았습니다. 일부 제작품, 양 진영 공통 보상, 평판, 던전 화폐 상점, 주술사 T0.5 연퀘도 포함합니다. 랜덤 수식어 아이템, 확인 전인 획득처, 공격대 재료가 필요한 제작품은 범위 밖입니다. 구간별 연퀘 보상은 해당 특성용 버전을 선택합니다.

장신구와 반지 쌍, 양손 또는 한손+보조장비를 하나의 선택 단위로 만듭니다. 고유 착용, 동일 제한 분류, 서로 배타적인 퀘스트 장신구를 검사합니다. 각 특성의 스탯 가중치로 후보를 좁힌 뒤 적중·숙련 상한을 고려해 세트를 구성합니다. 후보를 교체하고 주요 세트를 따로 시험한 뒤, 실측 상위 조합의 부위를 다시 결합해 평가합니다. **표시 순위는 이 탐색으로 평가한 조합 내 순위**입니다. 조건이나 고정 장비를 바꾸면 게임 안에서는 이미 평가한 전체 세트에서 다시 선택합니다.

### 로컬에서 재현

이번 데이터의 WoWSims 리비전은 `a73af7145111ce19c621e3b5f678553adf326907`입니다. Node 24, Go와 protoc, protoc-gen-go, Lua 5.1, Python 3가 필요합니다. Go 버전은 해당 WoWSims 리비전의 go.mod를 따릅니다. 아래 명령은 BiSFit 저장소 루트에서 실행합니다.

```sh
git clone https://github.com/wowsims/forever.git ../wowsims-forever
git -C ../wowsims-forever checkout a73af7145111ce19c621e3b5f678553adf326907
addon_dir="$(pwd)"
(
  cd ../wowsims-forever
  go install google.golang.org/protobuf/cmd/protoc-gen-go@"$(go list -m -f '{{.Version}}' google.golang.org/protobuf)"
  export PATH="$(go env GOPATH)/bin:$PATH"
  make sim/core/proto/api.pb.go
  go build -tags=with_db -o "$addon_dir/measure" "$addon_dir/dev/measure.go"
)
node dev/refresh.ts ../wowsims-forever ./measure
python3 dev/planner_data.py ../wowsims-forever/assets/database/db.json ./measure
lua5.1 dev/test.lua
python3 dev/package.py
```

`Data.lua`는 모든 계산이 성공한 뒤 교체됩니다. 고술·정술의 측정 엔진, 복술 주문 수치와 선별한 획득처의 근거는 [SOURCES.md](SOURCES.md)에 있습니다. 설치 ZIP에는 게임에서 쓰는 파일과 출처 고지만 포함합니다.
